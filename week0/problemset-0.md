# 🎮 Problem Set 0 – Scratch

## Polar-bear Dungeon Escape

**Polar Dungeon Escape** is a simple maze game created for **CS50's Problem Set 0** using Scratch.

The game begins with a short intro screen, followed by a **Start** menu. The player controls a polar bear and must find the key 🔑 while avoiding the monster 👾. The player starts with ❤️❤️❤️ three hearts, and each collision with the monster removes one heart. Losing all hearts results in a game over.

After collecting the key, the player can unlock the exit door 🚪 and win the game 🏆. If the player reaches the door without the key, the message **"You Need Key!"** is displayed.

## 🎮 Controls

- ⬅️➡️⬆️⬇️ Arrow Keys — Move the player.
- 🔑 Collect the key.
- 👾 Harvard the monster.
- 🚪 Reach the exit to win.
